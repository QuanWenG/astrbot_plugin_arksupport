# astrbot_plugin_arksupport

按群管理明日方舟助战 Excel 表，并让群友查询“这个干员该找谁借”。

## 功能

- 每个群通过 AstrBot UMO 独立存储，数据不会跨群。
- 支持群内自动登记，也支持在 WebUI 手动添加群聊 UMO。
- 可为每个 UMO 设置自定义备注，方便管理员辨认群绑定。
- 一个群可以导入一份或多份 `.xlsx` 工作簿。
- 自动识别 `官服`、`B服` 等工作表名称，并按区服展示结果。
- 按四列一组自动解析 `账号N`、`练度N`、`群成员昵称N`、`备注N`，
  支持扩展到任意槽位编号。
- 支持新增、指定替换和删除工作簿。
- 精确查询失败时提供相似干员名建议。
- 可选启用 LLM 兜底匹配，用于识别同音字、外号和错别字。
- 可选启动独立的多用户管理站点，支持邀请码、登录、私有备注和管理员权限。

## 使用方法

1. 推荐在目标群发送：

   ```text
   /助战登记
   ```

   也可以在管理页面展开“手动添加 UMO”，填写
   `平台实例:GroupMessage:群会话ID`。手动添加仅接受群聊 UMO。

2. 登录 AstrBot WebUI，打开插件详情中的“助战表管理”页面。可在群详情中新增或修改 UMO 备注。
3. 选择已登记群，上传 `.xlsx` 文件；可选择新增或替换已有工作簿。
4. 在该群查询：

   ```text
   /助战 风笛
   /助战 维娜 维多利亚
   ```

机器人会按区服列出账号、练度、群成员昵称和备注，例如：

```text
• 示例#0001｜练度：满专满潜 非满模组｜群id：群成员昵称｜备注：3级X模
```

空字段不会显示。已知干员没有助战时会明确提示；名称输入有误时会给出
相似候选。查询消息末尾会显示当前群全部工作簿中最近一次导入或替换的
日期，例如 `数据最后更新时间：2026-07-29`。

## LLM 兜底匹配

在 AstrBot WebUI 的插件配置中开启“启用 LLM 干员名兜底匹配”。
可以指定一个模型提供商；留空则使用该群当前会话的模型。

LLM 只会在精确匹配失败后调用，可能产生模型调用费用。插件会把当前群
已导入的干员名作为候选，并严格拒绝候选之外的模型结果，因此不会使用
其他群的表，也不会把模型凭空生成的名称用于查询。模型调用失败或无法
可靠判断时，查询会自动退回本地相似名称建议。

## Excel 格式

每个需要导入的工作表必须包含以下表头：

- `稀有度`
- `职业`
- `干员名`
- 至少一个 `账号N`，例如 `账号1`

同编号的以下表头可选：

- `练度N`
- `群成员昵称N`
- `备注N`

插件按表头末尾的编号关联同一槽位，不依赖固定列位置。旧版
`群名称N` 不再作为成员昵称导入；升级前导入的工作簿需要使用新版模板
重新上传或替换，才会显示群成员昵称。

插件会扫描工作表前 20 行定位表头。工作表名称作为查询结果中的区服名称。文件上限为 10 MiB；导入成功后只保存标准化数据和文件元信息，不保存原始 Excel。

## 数据位置

数据库位于 AstrBot 的：

```text
data/plugin_data/astrbot_plugin_arksupport/arksupport.sqlite3
```

删除工作簿会删除对应查询数据；删除已登记群会级联删除该群的全部工作簿数据。

## 独立多用户管理站点

在 AstrBot 插件配置中开启“启用独立多用户管理站点”后，插件默认监听
`0.0.0.0:12226`。浏览器应使用 AstrBot 所在服务器的实际 IP，例如：

```text
http://192.168.1.10:12226
```

独立站点默认关闭。首次开启前，先在 AstrBot 插件页的“注册邀请码”区域
生成邀请码，然后用户可在独立站点自行注册。

- 普通用户只能看到自己手动关联的 UMO 和自己的私有备注。
- 同一个 UMO 可被多个用户关联，对应工作簿由这些用户共享管理。
- 独立站点管理员可管理全部群、工作簿和普通账号，但不能授予管理员权限。
- AstrBot 插件页是超级管理员入口，可以管理全部账号、邀请码和管理员角色。
- 私有备注始终只有填写者本人可见。
- 管理端创建账号或重置密码时会生成仅显示一次的临时密码，用户登录后必须修改。

插件不提供内置 TLS。需要通过公网访问时，应使用 Nginx、Caddy 等反向代理
提供 HTTPS，并开启“仅通过 HTTPS 发送登录 Cookie”。如只允许本机反向代理，
可将监听地址改为 `127.0.0.1`。

账号密码使用 `scrypt` 加随机盐保存；登录会话可撤销且默认 7 天过期。
邀请码单次使用且默认 7 天过期。所有修改请求均进行 CSRF 校验。

## 兼容性

- AstrBot 4.26.7 及其插件 Pages API
- Python 3.10+
- Excel `.xlsx`

解析器直接读取 XLSX 标准数据 XML，不依赖 Excel 样式解析，因此可兼容部分带有非标准样式定义、但数据结构有效的工作簿。
